CodeAlpha Data Redundancy Removal System

Project Description

This project is developed using Python and SQLite to identify duplicate records and prevent redundant data from being stored in a database.

Features

- Add new records
- Detect duplicate names and email addresses
- Validate name and email inputs
- Store unique records in an SQLite database
- View stored records

Technologies Used

- Python
- SQLite
- Visual Studio Code

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python app.py

Learning Outcomes

- Python functions and conditional statements
- SQLite database operations
- Input validation
- Duplicate record detection
