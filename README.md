Python Task Manager

Project Description

A simple Task Manager application developed using Python and SQLite.

Features

- Add new tasks
- View all tasks
- Delete tasks
- Store tasks in an SQLite database

Technologies Used

- Python
- SQLite
- VS Code

How to Run

1. Install Python.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the command:
   
   "python app.py"

Learning Outcomes

- Python functions and loops
- SQLite database operations
- CRUD operations
- Basic error handling
